Custom software

Apps for management, clients, bookings, operations and needs specific to your business.

Many businesses run on a mix of spreadsheets, paper, WhatsApp groups and some program only one person uses. It works until it does not: an order gets lost, two people edit the same sheet, or nobody knows where a piece of data lives. Custom software brings that process into a single tool designed around how you actually work.

The problem it solves

Custom software makes sense when the process is specific to the business and off-the-shelf tools force you to adapt to them: paying for features you do not use, giving up important steps or duplicating data in several places. Common examples are customer and appointment management, orders and stock, job sheets or team coordination.

When we would not recommend it

It is not always the best option, and we prefer to say so before starting:

SituationWhat we usually advise
An existing tool covers almost everything you needUse it and, if needed, automate what it lacks
The process changes every few weeksStabilise it first; coding an undefined process is expensive
It is a one-off problem or affects one personA well-built spreadsheet or a small automation
The process is your own, repeats a lot and several people use itThis is where a custom tool usually pays off

How phased development works

We do not build everything at once. First we analyse the current process with the people who do it every day and map it step by step. From that we define a first version with the essentials, usually in use from 4 weeks, depending on scope. It is tested with real data and, with what we learn, the next phase is decided. You invest little at the start and every phase is justified by real use of the previous one.

We work with Node.js, PHP or Python on the server, MySQL or PostgreSQL databases and an interface built for how it will be used: office computer, tablet at the counter or phone on the go.

Scope: what is in and what is out

Included: process analysis, designing the application with you, phased development, testing with real data, documentation and initial support.

Keep in mind: the server the application runs on and any third-party services it needs (sending emails or SMS, payment gateway, storage) have their own cost, which we state in the quote. Moving data from a previous system is also quoted separately, because it depends a lot on the state that data is in.

What we need from you

  • Someone who knows the process and has time to explain it and test each phase.
  • Real examples: the sheets, forms or documents you use today, even if they are messy.
  • The odd cases: what happens when a customer cancels, when data is missing or when something is done differently from usual. That is where generic software fails.
  • Availability to review at the end of each phase.

How to measure whether it was worth it

Before starting we note how long the process takes today and which errors keep happening. With the application in use, we compare: time per task, errors, data that is no longer duplicated. If you want to do that calculation yourself, the calculator in our automation guide (in Spanish) works just as well to estimate the hours a repetitive task takes today.

Limits worth knowing

  • The first version will not do everything, on purpose. It is how you avoid paying for features nobody ends up using.
  • Software in use needs maintenance: security updates, backups and small adjustments. Plan for it from the start.
  • If during the analysis we see that an existing tool works for you, we will tell you, even if it means not doing the project.

FAQ

Common questions about this service.

Why not use a program that already exists?

If one works for you, that is what we will recommend. Custom software pays off when your process is your own and market tools force you to work worse or duplicate data.

Can I start with something small?

Yes, that is what we propose. A first version with the essentials and, from there, phases decided by real use.

Does it work on mobile?

Yes. The interface is designed for the device it will be used on: computer, tablet or phone, or several at once.

What happens after delivery?

There is documentation and an initial support period. Ongoing maintenance (updates, backups and adjustments) is agreed as a separate plan, with no lock-in.

What does the price depend on?

The number of processes the first version covers, user types and permissions, integrations with other tools and whether data needs migrating. With that we give you a fixed quote per phase.
