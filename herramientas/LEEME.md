# Herramientas

- `build-css.sh`: une y minifica las hojas de `public_html/assets/css/` en
  `assets/css/build/ltr/zyra.css` y `assets/css/build/rtl/zyra.css`, que son
  las que cargan las páginas. Ejecútalo después de editar cualquier CSS y
  sube el número `?v=` de las páginas para que los navegadores lo descarguen.
