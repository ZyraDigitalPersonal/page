Servicio

Desarrollo web

Webs corporativas, páginas para negocios locales, landing pages y rediseño de webs antiguas.

Qué incluye

  • Diseño a medida, sin plantillas cerradas
  • Rendimiento y SEO básico
  • Responsive real en móvil y tablet
  • Formulario de contacto, SSL y dominio
  • Una ronda de revisiones incluida

Para quién es

Negocios y profesionales que necesitan una presencia online que explique bien lo que hacen y les traiga contactos, no solo una web bonita.

Plazo orientativo
1–2 semanas la web esencial · 3–5 semanas la avanzada
Tecnología
Figma, HTML/CSS/JS y React o Next.js cuando el proyecto lo pide. Hosting según el caso.

Preguntas frecuentes

Dudas habituales de este servicio.

¿Puedo pedir cambios después?

Sí. Hay una ronda de revisiones incluida y, si más adelante quieres ampliar, se valora aparte antes de tocar nada.

¿Quién se queda el dominio y el alojamiento?

Tú. Podemos configurarlo nosotros o trabajar sobre el que ya tengas, pero las cuentas quedan siempre a tu nombre.

¿Cuánto cuesta?

Depende del alcance real, así que no publicamos tarifas cerradas. Nos cuentas qué necesitas por WhatsApp o formulario y te pasamos un presupuesto cerrado, sin partidas abiertas.

¿Qué pasa si el alcance cambia a mitad de proyecto?

Lo hablamos y ajustamos presupuesto y plazos antes de seguir — nunca se añade trabajo extra sin que lo sepas de antemano.
